Loja Virtual de Eletrônicos

Dupla: João Augusto e Horlian Gabriel

// Tema do projeto: Loja virtual de eletrônicos: aplicação web para consulta, busca e compra de produtos eletrônicos, com área do cliente (conta e carrinho) e área administrativa (cadastro, edição e exclusão de produtos).

Problema que o projeto resolve: Comprar eletrônicos pela internet ainda é confuso quando o catálogo é desorganizado, a busca é fraca e o carrinho não permite revisar ou remover itens com facilidade. Do lado da loja, atualizar preços, descrições e estoque sem uma área de gestão também atrasa o atendimento.

Esta aplicação concentra, em um só lugar:

o cadastro do cliente;

a busca de produtos;

a montagem e a revisão do carrinho;

a inclusão, a edição e a exclusão de produtos pelo administrador.

O objetivo é tornar a compra mais simples para o cliente e a manutenção do catálogo mais direta para a loja.

Funcionalidades principais: Criar uma conta de usuário, Pesquisar produtos pela barra de busca Adicionar produtos ao carrinho, Remover produtos do carrinho, Cadastrar novos produtos, Editar produtos já cadastrados, Excluir produtos do catálogo

Requisitos funcionais:Criar conta, Barra de pesquisa, Listar produtos, Adicionar ao carrinho, Visualizar carrinho, Remover do carrinho, Cadastrar produto, Editar produto, Excluir produto.

Requisitos não funcionais:Usabilidade, Desempenho, Segurança, Confiabilidade, Integridade dos dados, Manutenibilidade.
